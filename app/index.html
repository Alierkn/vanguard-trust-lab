    Role of the Demonstrator

    It is a supporting research artifact—not the project itself, a Vanguard audit, Pre-Check, or substitute for live Windows measurement.

    Make boundaries visible
    The diagram exposes where authority and failure impact change across user and kernel modes.
    Test a claim
    Deterministic samples make the difference between byte integrity and authenticity directly observable.
    Stay ethically bounded
    The demonstrator teaches the model without inspecting proprietary software, devices, accounts, memory, or traffic.
    Remain cross-platform
    Static web standards make the same exercise reproducible on macOS, Windows, and Linux.

    Evidence and Limitations

    Product statements, platform mechanisms, project inference, and demonstrator results stay separate.

    EvidenceUsed forImportant limitation
    Riot Security & Privacy Architecture (2020) Client, driver, and platform component model. Vendor description; private implementation details are not independently verified.

    Vanguard On-Demand (24 June 2026) Five public requirement groups and optional On-Demand operation. The checklist is a teaching summary, not the real Vanguard Pre-Check.
    Microsoft Runtime Attestation Report API OS-native driver attestation background. The API does not reveal Riot's private implementation.
    Microsoft User Mode and Kernel Mode Privilege separation and failure-impact background. Windows architecture documentation does not verify Vanguard's private implementation.
    NIST rootkit glossary Terminology used to avoid classifying software from privilege alone. A glossary definition is not a product assessment.

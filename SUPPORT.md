# Support

## Run the Interactive Security Demonstrator

```sh
npm ci --ignore-scripts
npm run ci
npm run serve
```

Open `http://127.0.0.1:8000`. If Web Crypto is unavailable from a `file://` URL, use this local server.

## Research corrections

Open a **Research correction** issue with the claim identifier, exact wording, primary source, and proposed correction. Do not attach copyrighted source copies or personal data.

## Product support

This repository cannot diagnose Vanguard, League of Legends, Riot accounts, Windows, drivers, firmware, or device eligibility. Use the current official support channel for the relevant product.

## Sensitive reports

Use the private process in [SECURITY.md](SECURITY.md); never disclose an unpatched repository vulnerability in an issue.

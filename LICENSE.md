# Licensing

This repository uses two licenses by content type:

- **Software code, tests, workflows, and build scripts:** MIT License (`LICENSES/MIT.txt`).
- **Original research prose, diagrams, and documentation:** Creative Commons Attribution 4.0 International (`LICENSES/CC-BY-4.0.txt`).

Third-party works are excluded. See `NOTICE.md`.

When a file combines code and substantial research prose, the implementation is MIT-licensed and the prose is CC BY 4.0.

`package.json` identifies the software package as MIT. `CITATION.cff` lists both licenses because it describes the combined research-software repository; that list does not make every file available under either license at the user's choice.

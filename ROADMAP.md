- Publish a clean-history, PII-free repository.

- Register public primary sources and bounded claims.
- Enable CI, CodeQL, Pages, Dependabot, secret scanning, and private vulnerability reporting.

- Add a documented, synthetic attestation fixture.

## v1.2.0 — Threat/control explorer

- Link public threat classes to controls, assumptions, and residual risk.
- Add keyboard-accessible interaction and deterministic tests.
- Keep the app static and dependency-free.

## 2026/2027 maintenance

- Promote Node 26 after its planned LTS transition and ecosystem validation.
- Remove Node 22 before its end-of-life window.
- Revalidate time-sensitive Riot and Microsoft claims before republication.
- Review immutable GitHub Action updates through Dependabot pull requests.

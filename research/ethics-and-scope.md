# Ethics and Scope

## Included

- study of public architecture and platform documentation;
- security-concept mapping from public primary sources;
- high-level threat and trust modeling;
- manual educational representation of public requirements;
- local SHA-256 hashing of user-selected or fixed harmless files;
- reproducible tests of the demonstrator.

## Excluded

- reverse engineering or binary inspection;
- exploit discovery or validation;
- cheat, bypass, evasion, or persistence development;
- memory manipulation or process injection;
- packet capture or interception;
- credential or account use;
- modification of Vanguard or game files;
- kernel-driver or firmware development;
- testing of systems without authorization;
- publication of operational instructions that facilitate abuse.

## Data handling

The app has no backend and uploads nothing. File contents remain inside the browser context. The selected baseline exists only in memory and is cleared when the page is refreshed. The repository contains no personal dataset, student record, player telemetry, player/account data, or captured network data. The hosting platform still exposes its ordinary repository-owner and public-contributor identities.

## Human participants

No human-subject experiment, survey, interview, or user profiling is conducted. Testing uses harmless fixed text samples and local interface checks; no participant identity is collected.

## Responsible communication

The project avoids a sensational "safe versus spyware" framing. It distinguishes authorization, disclosure, privilege, concealment, purpose, evidence, and failure impact. If a public source does not establish a claim, the correct result is an open question rather than speculation presented as fact.
